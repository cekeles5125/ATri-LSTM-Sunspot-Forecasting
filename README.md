# ATri-LSTM for Sunspot Number Forecasting

This repository contains the MATLAB implementation and supporting data
used for the forecasting experiments reported in the manuscript:

**"Sunspot Number Forecasting by Using Additive Triple LSTM Architecture
for Capturing Multi-Temporal Dynamics"**

The repository provides source code for two analyses performed with the
proposed **Additive Triple Long Short-Term Memory (ATri-LSTM)**
architecture:

1.  recursive multi-step forecasting performance on an independent
    historical test dataset; and
2.  10-year future sunspot number projections generated by independently
    trained ATri-LSTM models.

The ATri-LSTM architecture consists of three parallel LSTM branches with
**16, 64, and 128 hidden units** whose outputs are combined through
additive fusion.

## Dataset

The experiments use the **13-month smoothed monthly total sunspot number
(SSN)** time series obtained from the **World Data Center SILSO, Royal
Observatory of Belgium, Brussels**.

The MATLAB scripts read the observations from `SN_ms_tot_V2.0.xlsx`,
range `D7:D3313`.

Original SILSO data are publicly available at:

https://www.sidc.be/SILSO/

Users should cite the original SILSO data source as appropriate.

## 1. Forecast Performance on Test Dataset

Folder: `forecast performance on test dataset`

This experiment evaluates recursive multi-step forecasting using an
independent historical test dataset.

### Experimental Protocol

The sunspot sequence is chronologically divided into training data and
an independent test set containing the final **300 observations**. Test
observations are not used for network training.

Normalization parameters are calculated exclusively from the training
data and subsequently applied to the test data. The ATri-LSTM is trained
using one-step-ahead sequence prediction. Its long-term performance is
then evaluated recursively, with each predicted value used as input for
the subsequent forecasting step.

### Independent Training Runs

The complete training and recursive forecasting experiment was
independently repeated **10 times**. All runs use the same data
partition, preprocessing, architecture, and hyperparameters. Differences
among runs arise from stochastic network initialization and
optimization.

### `ForecastPerformancesOnTestDataset.m`

This script loads and preprocesses the data, constructs and trains
ATri-LSTM, performs recursive forecasting on the independent test
period, calculates the performance metrics, and saves the run results.

Metrics include RMSE, MSE, MAE, MAPE, and R².

The script is independently executed 10 times. Outputs may be stored as:

``` text
TestSet_10Veri_no1.mat
...
TestSet_10Veri_no10.mat
```

### `ReadData_ForecastPerformancesOnTestDataset.m`

This script loads the 10 independent run results, collects their
performance metrics, and calculates aggregated performance across the
model realizations.

## 2. Future Projections for ATri-LSTM

Folder: `future projections for ATri-LSTM`

This experiment generates long-term recursive projections using the
proposed ATri-LSTM.

### Projection Horizon

The trained model is recursively propagated for **120 months (10
years)** beyond the final historical observation.

These results are **model-based future projections rather than validated
future predictions**, because corresponding future observations are
unavailable.

### Independent Future Projection Runs

The complete training and future projection procedure was independently
repeated **40 times**. All runs use the same historical dataset,
preprocessing, architecture, training configuration, and projection
horizon. Differences arise from stochastic initialization and
optimization.

Accordingly, variability among these projections represents **inter-run
model variability** and is not a calibrated probabilistic prediction
interval.

### `FutureProjections.m`

This script loads the historical sequence, calculates normalization
parameters, constructs and trains ATri-LSTM, and generates a 120-month
recursive future projection.

The experiment is independently executed 40 times. Outputs may be stored
as:

``` text
FuturPre_10Veri_no1.mat
...
FuturPre_10Veri_no40.mat
```

### `ReadData_FutureProjections.m`

This script loads the 40 independently generated future projections and
combines them into a matrix. The ensemble-mean projection is calculated
across the independent model realizations.

The distribution of the 40 projections can also be used to characterize
the **5th--95th percentile inter-run spread** reported in the
manuscript. This spread represents stochastic inter-run variability and
**is not a calibrated prediction interval**.

## ATri-LSTM Architecture

  Branch                   LSTM Hidden Units
  ---------------------- -------------------
  Short-memory branch                     16
  Medium-memory branch                    64
  Long-memory branch                     128

  Responses                   1

## Reproducibility

Exact numerical results may vary between executions because
neural-network initialization and optimization are stochastic. The
manuscript therefore evaluates multiple independent realizations:

-   **10 independent runs** for recursive forecasting performance on the
    historical test dataset.
-   **40 independent runs** for the 10-year future projection analysis.
